# Contributing

Grazie per l’interesse in BootLens. Prima di proporre una modifica esegui restore, build Release e tutti i test. Aggiungi test per il comportamento osservabile, aggiorna tutte le quattro localizzazioni quando aggiungi testo visibile e non includere percorsi personali, secret, database locali o artefatti di build.

Le modifiche a startup devono avere test isolati e non devono alterare la configurazione di avvio della macchina usata per sviluppare. Le funzionalità Community devono restare opzionali e self-hostable.
