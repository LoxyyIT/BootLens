# Code of Conduct

Il progetto adotta un comportamento collaborativo, rispettoso e professionale. Non sono accettati molestie, discriminazioni, minacce, doxxing, impersonificazione o pubblicazione di dati personali.

Segnala problemi di comportamento ai maintainer indicati nel repository. Le segnalazioni saranno valutate con riservatezza e senza ritorsioni.
